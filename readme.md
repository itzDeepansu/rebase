# Project Name

A responsive web project built using **HTML**, **SCSS**, and **JavaScript** to demonstrate modern front-end development practices.

---

## 🚀 Features
- Responsive and mobile-friendly design  
- Modular SCSS structure for easy styling  
- Interactive UI built with vanilla JavaScript  
- Cross-browser compatibility  
- Lightweight and fast performance  

---

## 🛠️ Tech Stack
- **HTML5** – for structure  
- **SCSS (SASS)** – for styling and maintainable CSS  
- **JavaScript (ES6+)** – for interactivity
